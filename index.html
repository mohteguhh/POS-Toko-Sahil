Cadangan & Pemulihan Database Lokal (Offline)

Cocok untuk toko yang ingin 100% aman dan offline. Seluruh data kasir (produk, transaksi, piutang, nota kulak sales, pengeluaran, opname, paket bundling, pengaturan) dicadangkan secara lengkap ke file JSON.

💡 Data utama kasir sudah otomatis tersimpan aman di sistem komputer Anda.
📁 File backup diberi nama database-(nama toko)-DD-MM-YYYY.json dan tersimpan di folder backup database.

Sinkronisasi Online Cloud (Firebase Realtime Database)

Jika tidak dicentang, aplikasi berjalan 100% Offline di Database Lokal. Aktifkan fitur ini jika pembeli ingin memantau transaksi dari jarak jauh atau menghubungkan banyak kasir.
