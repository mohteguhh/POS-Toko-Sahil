Cadangan & Pemulihan Database Lokal (Offline)

Cocok untuk toko yang ingin 100% offline tanpa cloud. Seluruh data kasir (produk, transaksi, pelanggan, pengaturan) dapat dicadangkan ke file JSON dan disimpan di Flashdisk / Komputer.

Sinkronisasi Online Cloud (Firebase Realtime Database)

Jika tidak dicentang, aplikasi berjalan 100% Offline di Database Lokal. Aktifkan fitur ini jika pembeli ingin memantau transaksi dari jarak jauh atau menghubungkan banyak kasir.

Paket Cloud POS (Rp 50.000 / Bulan)

Belum Diatur

🔒 Konfigurasi Database Cloud (Terkunci Developer)
⚙️ Panel Konfigurasi Firebase (Mode Pengembang)
💡 Masukkan link database Firebase dari akun baru Anda di sini (contoh: https://nama-db-default-rtdb.asia-southeast1.firebasedatabase.app).

🚀 Migrasi Data Sekali Klik

Pindahkan seluruh produk, riwayat transaksi, pelanggan, dan shift kasir lokal Anda ke Firebase Realtime Database agar tersimpan aman di cloud.
